Monospace Slide

把每一页排在一张字符网格上

Nexustar2026-10-10

一页就是一张字符网格

西文字符占一列，汉字占两列，标题、表格和代码块的高度都是整数行。动笔之前，就能数出一页放得下多少东西。

  • 整页 96 列 × 18 行，接近 16:9
  • 内容区 88 列 × 14 行：左右各留 4 列，上留 1 行，下留 3 行
  • 标题占 2 行，后面空 1 行，正文还剩 11 行
  • 页脚里的标题和页码由 slides.js 自动填写

写多了，超出的部分会被裁掉，npm run check 会指出是哪一页、多了几行。

01

版式

封面、章节页、分栏，各对应 section 上的一个 class。

两栏：各 42 列

最常见的用法：左边写说明，右边放代码。

  • 栏间距 4 列
  • 代码块两侧各占 2 列，栏内还能放 38 列的代码
  • 每栏的内容都从顶端排起
<div class="cols">
  <div>
    <p>说明</p>
  </div>
  <pre><code>代码</code></pre>
</div>

三栏：各 28 列

列

宽度以 ch 为单位。西文一列、汉字两列，中英文混排照样对齐。

行

行高是字号的 1.6 倍，字体的制表符正好在这个高度上下相接。

线

线画在两行或两列之间的缝里，统一 2px 粗。

主栏加侧栏：56 列和 28 列

class用途正文行数
cover封面，内容贴底14
chapter章节页，内容贴底14
默认标题加正文11

表格每行占 2 行：文字在网格上，线在两行之间。

整张表另外多占 1 行，留给上下两条边线。

代码：一行最多 84 列

代码块和正文同一个颜色。超过 84 列的行，检查脚本会报出来。

function padToLines() {
  const line = lineHeight();
  for (const element of document.querySelectorAll("figure")) {
    const rest = element.getBoundingClientRect().height % line;
    if (rest > 0.01) element.style.paddingBottom = `${line - rest}px`;
  }
}
