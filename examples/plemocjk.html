PlemoCJK

中英文混排的等宽字体：半角和全角宽度 1:2

Nexustar2026-10-05

是什么

它是 PlemolJP 的扩展。PlemolJP 用 IBM Plex Mono 和 IBM Plex Sans JP 合成了一款日文编程字体，PlemoCJK 用同样的方法做了四个地区的版本：

  • SC 简体中文　TC 繁体中文　JP 日文　KR 韩文
  • 每个版本都有完整的 CJK 字符，同一个字优先用本地区的写法
  • 提供桌面字体，以及按需加载的网页字体

01

为什么

常见字体的半角 0.6em、全角 1em，宽度比 3:5，中英文混排很难对齐。

纯文本表格对不齐

这一页用的是 PlemoCJK，所以能对齐：

|title1| 标题2 |
|------|-------|
|内容01|context|

一般的编辑器里，汉字 1em 而字母 0.6em，含中文的行就短了一截。

凑成 1:2 的几种做法

字体半角全角代价
Sarasa Gothic0.5em1em英文多时太挤
PlemolJP / PlemoCJK0.528em1.056em字母缩放，汉字加间距
Maple Mono CN0.6em1.2em汉字之间偏松

PlemolJP 放弃了汉字 1em 的习惯，换来更和谐的排版，所以选它做基础。

同样字号下的对比

变体半角 / 全角箭头、框线用途

02

怎么做

扩充字体本身不复杂，精力都花在微调上。

歧义宽度的字符

有些字符在东亚编码里算全角，在别处算半角。Term 一律按半角，其他变体这样划分：

半角
拉丁符号 § ° ± × ÷
数学运算符 ∑ ∫ ≠ √ ∞
希腊和西里尔字母 α Ω А я
弯引号 “ ” ‘ ’
全角
箭头 ← → ⇒
几何图形 ■ ● ★
圈号和罗马数字 ① Ⅰ
框线，以及 … ※ №

画 ASCII art 时打开 hwid，全部按半角渲染。

框线和行高

框线按字体自带的 1.25 行高相接，到网页常用的 1.6 就断开了。ss16 把它们拉长：

pre {
  line-height: 1.6;
  font-feature-settings:
    "hwid", "ss16";
}

网页字体：一个 CSS 比十六个快

/* 1 */
@font-face {
  font-family: 'PlemoCJK SC';
  font-weight: 100;
  src: url('SC/PlemoCJK-SC-Thin.1.woff2');
  unicode-range: U+2DB-587;
}
/* …分片 1 的其余十五个样式… */

按 Noto Sans SC 的 unicode-range 切成两百多片，只下载用到的。

同一分片的规则排在一起，gzip 能去重：CSS 是 16 倍，传输不到 2 倍。
